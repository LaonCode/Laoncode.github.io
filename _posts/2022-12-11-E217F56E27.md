            <div class="contents_style"><p data-ke-size="size16">오늘은 Bandit5 문제를 해결해 보자.</p>
<p><figure class="imageblock alignCenter" data-ke-mobileStyle="widthOrigin" data-filename="화면 캡처 2022-12-11 171118.png" data-origin-width="1099" data-origin-height="304"><span data-url="/assets/images/posts/8fa86c7e32106b10fb64a2b2d9800f596fa59fbe.png" data-phocus="/assets/images/posts/8fa86c7e32106b10fb64a2b2d9800f596fa59fbe.png"><img src="/assets/images/posts/8fa86c7e32106b10fb64a2b2d9800f596fa59fbe.png" loading="lazy" width="1099" height="304" data-filename="화면 캡처 2022-12-11 171118.png" data-origin-width="1099" data-origin-height="304"/></span></figure>
</p>
<p data-ke-size="size16"><span style="color: #666666;">Bandit의 Level 5의 문제를 살펴보니 지난번 접속했던 Bandit 4에 inhere 디렉토리에서 "사람이 읽을 수 있는" 유일한 파일에 비밀번호가 저장되어 있다고 되어있다. 추가로 터미널이 더러워졌다면 reset 명령어를 사용하라고 나온다.</span><span style="color: #666666;"></span></p>
<p data-ke-size="size16"><span style="color: #666666;"><b>Tip.</b> 이때 reset 명령어를 더 간편하게 하고 싶다면 ctrl+l을 누르면 reset 명령어를 사용한 효과와 동일하게 나타나니 참고하길 바란다.</span></p>
<p><figure class="imageblock alignLeft" data-ke-mobileStyle="widthOrigin" data-filename="화면 캡처 2022-12-11 171459.png" data-origin-width="755" data-origin-height="181"><span data-url="/assets/images/posts/85240795b30d04b5ed6a4b5e66b63017008d4f75.png" data-phocus="/assets/images/posts/85240795b30d04b5ed6a4b5e66b63017008d4f75.png"><img src="/assets/images/posts/85240795b30d04b5ed6a4b5e66b63017008d4f75.png" loading="lazy" width="755" height="181" data-filename="화면 캡처 2022-12-11 171459.png" data-origin-width="755" data-origin-height="181"/></span></figure>
</p>
<p data-ke-size="size16">먼저 ls로 어떤 파일들이 있는지 확인 후 inhere디렉토리에 비밀번호가 있는 파일이 있다고 했으니 cd inhere 명령어를 사용하여 inhere디렉토리로 가보도록 하자. <span style="letter-spacing: 0px;">(</span><b>Tip.</b><span style="letter-spacing: 0px;"> cd를 작성 다음 Tab을 누르면 자동완성이 되어 cd inhere/ 명령어가 자동으로 완성되니 참고로 알아두도록 하자.) inhere디렉토리에 들어왔으니 ls 명령어로 어떤 파일들이 있는지 확인해 보니 ....? 10가지나 되는 파일들이 있어 당황스러울 수 있다. 하지만 문제에서는 "사람이 읽을 수 있는" 파일을 찾아야 비밀번호를 얻을 수 있다고 한다. 이때 나도 꽤 오래 걸린 부분이다. 일단 먼저 모든 파일들의 정보를 한번 ls -al 또는 ls -a -l 로 찾아보면(ls의 추가 옵션은 Linux에 글이 올려져 있으니 확인하면 도움이 될 것이라 생각한다.)</span></p>
<p><figure class="imageblock alignLeft" data-ke-mobileStyle="widthOrigin" data-filename="화면 캡처 2022-12-11 173046.png" data-origin-width="744" data-origin-height="391"><span data-url="/assets/images/posts/a1f436991e32727bcaf4393c6c37bab9c1bec8cd.png" data-phocus="/assets/images/posts/a1f436991e32727bcaf4393c6c37bab9c1bec8cd.png"><img src="/assets/images/posts/a1f436991e32727bcaf4393c6c37bab9c1bec8cd.png" loading="lazy" width="744" height="391" data-filename="화면 캡처 2022-12-11 173046.png" data-origin-width="744" data-origin-height="391"/></span></figure>
</p>
<p data-ke-size="size16">확인해 보니 이전에 ls 명령어로 확인한 10개의 파일이 모두 동일한 정보로 나오고 사람이 읽을 수 있는지 없는지 판단이 불가능해 보인다. 그래서 Google과 bandit의 유용한 읽기 자료를 사용해서 찾아보기로 하였다. 그 결과 사용해야 하는 명령어는 file 명령어였다. file 명령어는 파일의 종류 확인 및 파일의 속성 값을 확인할 때 사용하는 명령어라고 합니다. 그럼 한번 file 명령어를 사용해 1개씩 다 해보는 "노동"의 장면을 마주해 보자. (<b>Tip.</b> 파일 이름에 "-"이 포함되어 있어 file -file0로는 확인할 수 없다. 이와 관련된 사항은 Level2. Bandit2 로그인 참고하면 좋을 것 같다.)</p>
<p><figure class="imageblock alignLeft" data-ke-mobileStyle="widthOrigin" data-filename="화면 캡처 2022-12-11 173925.png" data-origin-width="727" data-origin-height="806"><span data-url="/assets/images/posts/9b50df1c4914ec459c849309abdce6b759708ea4.png" data-phocus="/assets/images/posts/9b50df1c4914ec459c849309abdce6b759708ea4.png"><img src="/assets/images/posts/9b50df1c4914ec459c849309abdce6b759708ea4.png" loading="lazy" width="727" height="806" data-filename="화면 캡처 2022-12-11 173925.png" data-origin-width="727" data-origin-height="806"/></span></figure>
</p>
<p data-ke-size="size16">이렇게 힘들게 file ./-file0, file ./-file01....을 해보니 ./-file07 빼고는 다&nbsp; data이고 ./-file07은 ASCII text라고 나와 있는 것을 확인할 수 있다. 그럼 ASCII text가 무엇일까? 이런 경우에는 검색해 보는 것이 가장 좋다.</p>
<p><figure class="imageblock alignLeft" data-ke-mobileStyle="widthOrigin" data-filename="화면 캡처 2022-12-11 174329.png" data-origin-width="701" data-origin-height="403"><span data-url="/assets/images/posts/4139088e6a3512c543a77b0774620d2059b1fd58.png" data-phocus="/assets/images/posts/4139088e6a3512c543a77b0774620d2059b1fd58.png"><img src="/assets/images/posts/4139088e6a3512c543a77b0774620d2059b1fd58.png" loading="lazy" width="701" height="403" data-filename="화면 캡처 2022-12-11 174329.png" data-origin-width="701" data-origin-height="403"/></span></figure>
</p>
<p data-ke-size="size16">뜻을 확인해 보니 사람이 확인할 수 있는 파일인 것은 확실한 것 같다. (ASCII에 대한 자세한 것은 추후 다뤄보도록 하겠다.)</p>
<p data-ke-size="size16">그런데 우리는 방금까지 "노동"을 해가면서 까지 이 사실 하나를 알아내기 위해 열심히 10번의 작업을 반복했다. 만약 10개가 아닌 100, 1000개일 때도 이렇게 해야 하는 것일까? 답은 "아니다"이다 이 "노동"의 작업을 한 번에 해결하는 방법이 있다.</p>
<p data-ke-size="size16">바로 file ./-* 명령어이다. 여기서 현재 경로에 있는 -가 포함된 모든 파일을 확인한다는 뜻입니다. 한번 해보도록 하자. (<b>Tip.</b> 여기서 "*"은 파일명 관리할 때 사용하는 것들을 통틀어서 와일드카드라고 하는데 "*"은 그중 하나로 "모든"이라고 알아두면 좋을 것 같다.)</p>
<p><figure class="imageblock alignLeft" data-ke-mobileStyle="widthOrigin" data-filename="화면 캡처 2022-12-11 175003.png" data-origin-width="317" data-origin-height="184"><span data-url="/assets/images/posts/bc51385d0ecf5681f67ee6da0af7ed8a0469126c.png" data-phocus="/assets/images/posts/bc51385d0ecf5681f67ee6da0af7ed8a0469126c.png"><img src="/assets/images/posts/bc51385d0ecf5681f67ee6da0af7ed8a0469126c.png" loading="lazy" width="317" height="184" data-filename="화면 캡처 2022-12-11 175003.png" data-origin-width="317" data-origin-height="184"/></span></figure>
</p>
<p data-ke-size="size16">이렇게 우리의 "노동"의 순간이 허무하게 느껴지는 순간이기도 하다. 그럼 정말 ASCII text가 사람이 읽을 수 있는 파일인지 직접 확인해 보도록 하자.</p>
<p><figure class="imageblock alignLeft" data-ke-mobileStyle="widthOrigin" data-filename="화면 캡처 2022-12-11 175158.png" data-origin-width="362" data-origin-height="304"><span data-url="/assets/images/posts/275d20ddffc0f31de2f6a5e72dfc62697888a8e1.png" data-phocus="/assets/images/posts/275d20ddffc0f31de2f6a5e72dfc62697888a8e1.png"><img src="/assets/images/posts/275d20ddffc0f31de2f6a5e72dfc62697888a8e1.png" loading="lazy" width="362" height="304" data-filename="화면 캡처 2022-12-11 175158.png" data-origin-width="362" data-origin-height="304"/></span></figure>
</p>
<p data-ke-size="size16">이렇게 cat 명령어로 확인해 본 결과 비밀번호가 나오는 것을 확인할 수 있다. 그럼 bandit5에 접속해 보도록 하자.</p>
<p><figure class="imageblock alignLeft" data-ke-mobileStyle="widthOrigin" data-filename="화면 캡처 2022-12-11 175353.png" data-origin-width="701" data-origin-height="933"><span data-url="/assets/images/posts/f97faf3d32b1d67fd8307924aed722c13eea250f.png" data-phocus="/assets/images/posts/f97faf3d32b1d67fd8307924aed722c13eea250f.png"><img src="/assets/images/posts/f97faf3d32b1d67fd8307924aed722c13eea250f.png" loading="lazy" width="701" height="933" data-filename="화면 캡처 2022-12-11 175353.png" data-origin-width="701" data-origin-height="933"/></span></figure>
</p>
<p data-ke-size="size16">이렇게&nbsp; bnadit5에 접속이 된 걸 확인할 수 있다.</p>
<p data-ke-size="size16"><span style="color: #666666;">*위 나와있는 방법 말고도 많은 방법들이 있으니 다양한 방법으로 시도해 보는 것을 추천한다.</span></p>
<p data-ke-size="size16"><span style="color: #666666; text-align: start;">*본 글은 프로그래밍 공부를 하며 작성한 글이며, 글에 오류가 있다면 꼭 댓글로 알려주시면 감사하겠습니다.</span></p></div>
