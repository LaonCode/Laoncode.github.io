이번 주차에는 if, while, for 등의 제어문에 대해 알아보고자 한다. 우리는 지금까지 나무, 돌과 같은 재료(자원)인 자료형에 대해 알아보았다. 이제 뼈대를 이룰 제어문을 자료형을 기반으로 알아보자.

#if문은 왜 필요할까?

한번 이런 상상을 해보자.

빨간불이면 멈추고, 초록불이면 건 간다.

이 상황은 우리가 매일 같이 일어나는 상황일 것이다. 프로그래밍도 사람이 하는 것이기 대문에 위 문장처럼 주어진 조건을 판단한 후 그 상황에 맞게 처리해야 할 경우가 생긴다. 이렇듯 프로그래밍에서 조건을 판단하여 해당 조건에 맞는 상황을 수행하는 데 쓰는 것이 바로 if문이다.

그렇다면 위 상황을 파이썬으로 표현해 보자.

>>> red = True
>>> if red:
          print("멈춰라")
       else:
          print("건너가라")

멈춰라

아래 순서도는 '건너가라'는 문장이 출력되는 과정을 보여 준다. 프로그램 실행 과정을 순서도로 그려 보면 훨씬 이해하기 쉬울 것이다.

#if문의 기본 구조

if문의 구조는 어떻게 이루워져 있을까?

위에서 보았던 예시처럼 조건문을 테스트해서 참이면 if문 바로 다음 문장(if 블록)들을 수행하고, 조건문이 거짓이면 else문 다음 문장(else 블록)들을 수행하게 된다. 이러한 이유로 인해 else문은 if문 없이 독립적으로 사용할 수 없다는 구조도 함께 가지고 있다. 또한 if문을 사용할 때 뒤에 콜론(:)을 붙이는 것을 잊지말자.

#들여쓰기

if문을 만들 때 if 조건문: 바로 아래 문장부터 if문에 속하는 모든 문장에 들여쓰기(indentation)를 해주어야 한다. 이것이 if문의 가장 중요한 점이라고 생각한다. 만약 들여쓰기의 중요성을 무시한다면 아래와 같은 오류가 뜰 것이다.

들여쓰기 할 때도 들여쓰기의 너비가 다르기 때문에 주의해야한다. 따라서 들여쓰기는 언제나 같은 너비로 해야한다.

#조건문 자세히 톺아보기

if 조건문에서 '조건문'이란 참과 거짓을 판단하는 문장을 말한다. 이제부터 몇가지 더 알아보자

#STEP1. 비교연산자

조건문에는 비교 연산자(<, >, ==, !=, >=, <=)를 사용한다.

비교 연산자 설명
x < y x가 y보다 작다
x > y x가 y보다 크다
x == y x와 y가 같다
x != y x와 y가 같지 않다
x >= y x가 y보다 크거나 같다
x <= y x가 y보다 작거나 같다

그럼 한번 예시를 통해 어떻게 활용되는지 알아보자.

아래 상황을 보면 money >= 3000 조건문이 거짓이 되기 때문에 else문 다음 문장을 수행하게 된다.

>>> moeny = 2000
>>> if money >= 3000:
            print("택시를 타고 가라")
        else:
             print("걸어 가라")
걸어가라

#STEP2. and, or, not

조건문에서 조건을 판단하기 위해 사용하는 다른 연산자로는 and, or, not이 있다. 각각의 연산자는 아래와 같이 동작한다.

연산자 설명
x or y x와 y 둘 중에 하나만 참이어도 참이다
x and y x와 y 모두 참이어야 참이다
not x x가 거짓이면 참이다

아래 예시를 통해 or 연산자를 사용해보자.

money는 2000이라 조건에 성립되지 않지만 card가 True이기 대문에 money >= 3000 or card 조건문이 참이 된다. 따라서 if 문 다음 '택시를 타고 가라' 문장이 출력된다.

>>> moeny = 2000
>>> card = True
>>> if money >= 3000 or card:
            print("택시를 타고 가라")
        else:
             print("걸어 가라")
택시를 타고 가라

#STEP3. x in s, x not in s

이제 파이썬에서만 볼 수 있는 조건문을 알아보자

in not in
x in 리스트 x not in 리스트
x in  튜플 x not in 튜플
x in 문자열 x not in 문자열

가장먼저 in에 대해 알아보자.

영어 단어 in의 뜻은 '~안에'라는 것을 생각해 보면 이해가 쉬울 것이다. 아래 예시를 살펴보자.

첫번째 줄은 '[1, 2, 3]이라는 리스트 안에 1이 있는가?' 조건문이다. 1은 [1, 2, 3] 안에 있으므로 참이 되어 True를 돌려준다. 두번째 줄은 '[1, 2, 3] 리스트 안에 1이 없는가?' 조건문이다. 1은 [1, 2, 3] 안에 있으므로 거짓이 되어 False를 돌려준다.

>>> 1 in [1, 2, 3]
True
>>> 1not in [1, 2, 3]
False

두번째로 튜플에 대해 알아보자

아래는 튜플과 문자열에 적용한 예시이다.

>>> 'a' in ('a', 'b', 'c')
True
>>> 'j' not in 'python'
True

만약 조건문에서 아무 일도 하지 않게 하고 싶다면 어떻게 해야할까?

이럴 때 사용하는 것이 바로 pass이다. 아래 예시를 살펴보자.

pocket 리스트 안에 money 문자열이 있기 때문에 if문 다음 문장인 pass가 수행되고 아무 결괏값도 보여주지 않는다.

>>>pocket = ['card', 'money', 'cellphone']
>>> if 'card' in pocket:
            pass
        else:
             print("카드를 꺼내라")

#다양한 조건을 판단하는 elif

if와 else만으로 다양한 조건을 모두 판단할 수 있을까?

그러긴 어려울 것이다. 만약 아래 예시를 if와 else만으로 판단한다면 어떨까?

아래 문장을 보면 판단하는 부분이 두 군데가 존재한다. 먼저 주머니에 돈이 있는가?, 주머니에 돈이 없으면 카드가 있는가?를 판단해야한다. 한번 if와 else만으로 코드를 구성해 보자.

주머니에 돈이 있으면 택시를 타고, 주머니에 돈은 없지만 카드가 있으면 택시를 타고, 돈도 없고 카드도 없으면 걸어가라.

뭔가 복잡해 보이지 않는가? 이런 복잡한 느낌을 해소하기 위해 파이썬에서는 다중 조건을 판단할 때 사용하는 elif가 존재한다.

>>>pocket = ['paper', 'cellphone']
>>> card = True
>>> if 'money' in pocket:
             print("택시를 타고 가라")
        else:
             if card:
                 print("택시를 타고 가라")
              else:
                  print("카드를 꺼내라")
택시를 타고 가라

elif를 활용하여 코드를 수정해보자.

>>>pocket = ['paper', 'cellphone']
>>> card = True
>>> if 'money' in pocket:
             print("택시를 타고 가라")
        elif card:
             print("택시를 타고 가라")
        else:
              print("걸어가라")
택시를 타고 가라

위 코드를 바탕으로 봐 보면 elif는 이전 조건문이 거짓일 대 수행된다. if, elif, else를 모두 사용할 때 기본 구조는 아래와 같다.

if 조건문:
   수행할 문장1
   수행할 무장2
   ...
elif 조건문2:
     수행할 문장1
     수행할 문장2
     ...
...
elif 조건문N:
      수행할 문장1
      수행할 문장2
      ...
...
else:
       수행할 문장1
       수행할 문장2
        ...

아래 그림에서 볼 수 있듯이 elif는 개수에 제한 없이 사용할 수 있다는 것을 알 수 있다.

#if문 더 간략하게 작성하기

만약 아래와 같은 상황 처럼 if문 다음에 수행할 문장이 한 줄, else문 다음에 수행할 문장도 한 줄밖에 안되는 경우 더 간단하게 쓸 방법이 없을까?

>>> if 'money' in pocket:
           pass
       else:
           print("카드를 꺼내라")

수행할 문장이 한 줄일 때 조금 더 간랸하게 코드를 작성하는 방법이 있다. 아래 코드를 살펴보자.

if문 다음 수행할 문장을 콜론(:) 뒤에 바로 적어주는 방법이 있다. 기억해두면 좋을 것 같다.(else문 역시 동일하다.)

>>> pocket = ['paper', 'money'. 'cellphone']
>>> if 'money' in pocket: pass
       else: print("카드를 꺼내라")

#조건부 표현식

아래와 같은 코드를 살펴보자.

아래 코드는 score가 60 이상일 경우 message에 문자열 "success"를, 아닐 경우에는 "failure"를 대입하는 코드이다. 

if score >= 60:
    message = "success"
else:
     message = "failure"

파이썬의 조건부 표현식(conditional expression)을 사용하면 위 코드를 아래와 같이 간단히 표현할 수 있다.

message = "success" if score >= 60 else "failure"
