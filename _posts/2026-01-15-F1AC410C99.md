<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#while문의 기본 구조</h4>
<p data-ke-size="size16">반복해서 문장을 수행해야 할 경우 while문을 사용한다. 그래서 while문을 반복문이라고도 부른다.</p>
<p data-ke-size="size16">아래는 while문의 기본 구조이다.</p>
<blockquote data-ke-style="style3">while 조건문:<br />&nbsp; &nbsp; &nbsp;수행할 문장1<br />&nbsp; &nbsp; &nbsp;수행할 문장2<br />&nbsp; &nbsp; &nbsp;수행할 문장3<br />&nbsp; &nbsp; &nbsp;...</blockquote>
<p data-ke-size="size16">while문은 조건문이 참인 동안에 while문 아래의 문장이 반복해서 수행된다.</p>

</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#while문 만들기</h4>
<p data-ke-size="size16">여러 가지 선택지 중 하나를 선택해서 입력받는 예시를 만들어 보겠다. 아래와 같이 여러 줄짜리 문자열을 입력한다.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; prompt = """<br />&nbsp; &nbsp; &nbsp; &nbsp;1. January<br />&nbsp; &nbsp; &nbsp; &nbsp;2. February<br />&nbsp; &nbsp; &nbsp; &nbsp;3. March<br />&nbsp; &nbsp; &nbsp; &nbsp;4. April<br />&nbsp; &nbsp; &nbsp; &nbsp;<br />&nbsp; &nbsp; &nbsp; &nbsp;Enter number: """"</blockquote>
<p data-ke-size="size16">이어서 number 변수에 0을 먼저 대입한다. 이렇게 변수르 먼저 설정해 놓지 않으면 다음에 올 while문의 조건문인 number !=4에서 변수가 존재하지 않는다는 오류가 발생한다.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; number = 0<br />&gt;&gt;&gt; while number != 4:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; print(prompt)<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; number = int(input())<br /><br />1. January<br />2. February<br />3. March<br />4. April<br /><br />Enter number:</blockquote>
<p data-ke-size="size16">While문을 보면 number가 4가 아닌 동안 prompt를 출력하고 사용자로부터 번호를 입력받는다. 아래 결과처럼 사용자가 값 4를 입력하지 않으면 계속해서 prompt를 출력한다.</p>
<blockquote data-ke-style="style3">Enter number:<br />1<br /><br />1. January<br />2. February<br />3. March<br />4. April</blockquote>
<p data-ke-size="size16">4를 입력하면 조건문이 거짓이 되어 while문을 빠져나가게 된다.</p>
<blockquote data-ke-style="style3">Enter number:<br />4<br />&gt;&gt;&gt;</blockquote>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#while문 강제로 빠져나가기</h4>
<p data-ke-size="size16">while문은 조건문이 참인 동안 계속해서 while문 안의 내용을 반복적으로 수행한다. 다만 강제로 while문을 빠져나가고 싶을 때가 있을 것 이다. 예를 들어볼까? 우리가 음식점에 가서 키오스크로 음식을 주문한다. 만약 재료가 있다면 키오스크에서 음식은 계속 판매될 것이다. 음식점 주인은 음식의 재료가 얼마나 남았는지 수시로 확인해야한다. 만약 음식의 재료가 다 떨어졌다면 키오스크에서 판매를 중단하고 "Sold out"문구를 고객에게 보여주어야 한다. 이렇게 판매를 강제로 멈추가 하는 것이 바로&nbsp; break문이다.</p>
<p data-ke-size="size16">이것을 파이썬 코드를 작성해보자.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; ingredient = 10<br />&gt;&gt;&gt; money = 3000<br />&gt;&gt;&gt; while money:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;print("결재가 완료되었으니 주문접수를 합니다.")<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;ingredient = ingredient - 1<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;print("남은 재료의 양은 %d개 입니다." %&nbsp; ingredient)<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;if ingredient == 0:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;print("재료가 다 소진되었습니다. 판매를 중지합니다.")<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;break</blockquote>
<p data-ke-size="size16">money가 3000으로 고정되어 있으므로 while money:에서 조건문인 money는 0이 아니기 때문에 항상 참이된다. 따라서 무한히 반복되는 무한 루프가 돌게된다. 그리고&nbsp; while문의 내용을 한 번 수행할 때마다 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">ingredient<span> = <span style="background-color: #fcfcfc; color: #666666; text-align: left;">ingredient - 1에 의해서 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">ingredient<span> 의 개수가 1개씩 줄어든다. 만약 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">ingredient<span>&nbsp;</span></span> 가 0이 되면 if <span style="background-color: #fcfcfc; color: #666666; text-align: left;">ingredient<span>&nbsp;</span></span><span style="background-color: #fcfcfc; color: #666666; text-align: left;"><span> </span></span>== 0: 문장에서 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">ingredient<span>&nbsp;</span></span><span style="background-color: #fcfcfc; color: #666666; text-align: left;"><span> </span></span>==0:이 되므로 if문 다음 문장 "재료가 다 소진되었습니다. 판매를 중지합니다."가 수행되고 break문이 호출되어 while문을 빠져나가게 된다.</span></span></span></span></span></p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#while문의 맨 처음으로 돌아가기</h4>
<p data-ke-size="size16">while문 안의 문장을 수행할 때 입력 조건을 검사해서 조건에 맞지 않으면 while문을 빠져나간다. 그런데 프로그래밍을 하다 보면 while문을 빠져나가지 않고 while문의 맨 처음(조건문0으로 다시 돌아가게 만들고 싶은 경우가 생기게 된다. 이때 사용하는 것이 바로 continue문이다.</p>
<p data-ke-size="size16">1부터 10까지으 ㅣ숫자 중에서 홀수만 출력하는 것을 while문을 사용해서 작성한다고 해보자. 아래와 같이 만들 수 있을 것이다.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; a = 0<br />&gt;&gt;&gt; while a &lt; 10:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; a = a+1<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; if a % 2 ==0: continue<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; print(a)<br /><br />1<br />3<br />4<br />7<br />9</blockquote>
<p data-ke-size="size16">1부터 10까지의 숫자 중 홀수만 출력하는 예시이다. a가 10보다 작은 동안 a는 1만큼씩 계속 증가한다. if a % 2==0(a를 2로 나누었을 대 나머지가 0인 경우)이 참이 되는 경우는 a가 짝수일 때이다. 즉 a가 짝수이면 continue 문장을 수행한다. 이 continue문은 while문의 맨 처음(whrjsans: a&lt;10)으로 돌아가게 하는 명령어이다. 따라서 a가 짝수이면 print9a)는 수행되지 않을 것이다.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#무한 루프</h4>
<p data-ke-size="size16">이번에는 무한 루프(Loop)에 대해 알아보자. 무한 루프란 무한히 반복한다는 의미이다. 일반적으로 사용하는 프로그램 중에서 무한 루프 개념을 사용하지 않는 프로그램은 거의 없다. 그만큼 중요하고 자주 사용한다.</p>
<p data-ke-size="size16">파이썬에서 무한 루프는 while문으로 구현할 수 있다. 아래는 무한루프의 기본 형태이다. while문의 조건문이 True이므로 항상 참이 된다. 따라서 while문 안에 있는 문장들은 무한하게 수행된다.</p>
<blockquote data-ke-style="style3">while True:<br />&nbsp; &nbsp; 수행할 문장1<br />&nbsp; &nbsp; 수행할 문장2<br />&nbsp; &nbsp; ...</blockquote>
<p data-ke-size="size16">아래는 무한 루프의 예시이다. 이 문장은 영원히 출력된다. 하지만 아무 의미 없이 무한 루프를 돌리고 싶지 않을 것이다. 이런 경우 ctrl+c를 눌러 빠져나갈 수 있다는 것을 기억하자.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; While True:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;print("Ctrl+c를 눌러야&nbsp; while문을 빠져나갈 수 있습니다.")<br /><br />Ctrl+c를 눌러야&nbsp; while문을 빠져나갈 수 있습니다.<br />Ctrl+c를 눌러야&nbsp; while문을 빠져나갈 수 있습니다.<br />Ctrl+c를 눌러야&nbsp; while문을 빠져나갈 수 있습니다.<br />...</blockquote>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#for문</h4>
<p data-ke-size="size16">파이썬에서 while문과 비슷한 녀석이 하나 있다. 바로 for문이다.</p>
<p data-ke-size="size16">for문은 while문과 같이 반복문이며 매우 유용하고 문장 구조가 한눈에 쏙 들어온다는 장점이 있다. 이제 for문에 대해 자세하게 알아보자.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#for문의 기본 구조</h4>
<p data-ke-size="size16">for문의 기본 구조는 아래오 ㅏ같다.</p>
<p data-ke-size="size16">리스트나 튜플, 문자열의 첫 번째 요소부터 마지막 요소까지 차례로 변수에 대입되어 '수행할 문장1', '수행할 문장2'등이 수행된다.</p>
<blockquote data-ke-style="style3">for 변수 in 리스트(또는 튜플, 문자열):<br />&nbsp; &nbsp; 수행할 문장1<br />&nbsp; &nbsp; 수행할 문장2<br />&nbsp; &nbsp; &nbsp;...</blockquote>
<p data-ke-size="size16">그럼 이제 실제 코드를 통해 for 문을 이해해보자.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#STEP.1 전형적인 for문</h4>
<p data-ke-size="size16"><span style="background-color: #fcfcfc; color: #666666; text-align: left;">['one', 'two', 'three'] 리스트의 첫 번째 요소인 'one'이 먼저 i 변수에 대입된 후 print(i) 문장을 수행한다. 다음에 두 번째 요소 'two'가 i 변수에 대입된 후 print(i) 문장을 수행하고 리스트의 마지막 요소까지 이것을 반복한다.<br /></span></p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; test_list = ['one', 'two', 'three']<br />&gt;&gt;&gt; for i in test_list:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; print(i)<br />one<br />two<br />three</blockquote>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#STEP.2 전형적인 for문의 사용</h4>
<p data-ke-size="size16">아래 코드는 a리스트의 요솟값이 튜플이기 때문에 각각의 요소가 자동으로 (first, last) 변수에 대입된다.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; a = [(1,2), (3,4), (5,6)]<br />&gt;&gt;&gt; for (first, last) in a:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; print(first = last)<br />3<br />7<br />11</blockquote>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#STEP.3 for문의 응용</h4>
<p data-ke-size="size16">for문의 쓰임새를 알아보기 위해 아래와 같이 가정해보자.</p>
<blockquote data-ke-style="style3">총 5명의 학생이 시험을 보았다. 시험 점수가 80점이 넘으면 Pass이고 그렇지 않으면 재수강이다. pass인지 재수강인지 결과를 보여 주시오.</blockquote>
<p data-ke-size="size16">우선 학생 5명의 시험 점수를 리스트 해보자.</p>
<blockquote data-ke-style="style3">student = [100, 50, 77, 67, 90]</blockquote>
<p data-ke-size="size16">첫번째 학생은 100점이고 다섯번째 학생은 90점이다.</p>
<p data-ke-size="size16">이런 점수를 차례로 검사해서 Pass인지 재수강인지 통보해 주는 시스템을 만들어보자.</p>
<p data-ke-size="size16">각각의 학생에게 번호를 붙여주기 위해 number 변수를 사용하였다. 점수 리스트 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">student</span>에서 차례로 점수를 꺼내어 score라는 변수에 대입하고 for문 안의 문장들을 수행한다. 우선 for문이 한 번씩 수행될 때마다 number는 1씩 증가한다.</p>
<blockquote data-ke-style="style3">student = [100, 50, 77, 67, 90]<br />number = 0<br />for score in student:<br />&nbsp; &nbsp; &nbsp; number = number + 1<br />&nbsp; &nbsp; &nbsp; if score &gt;= 80:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; print("%d번 학생은 Pass입니다." % number)<br />&nbsp; &nbsp; &nbsp; else:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; print("%d번 학생은 재수강입니다." % number)</blockquote>
<p data-ke-size="size16">이 코드를 실행하면 score가 80 이상일 때 Pass 메시지를 출력하고 80을 넘지 않을 때 재수강 메시지를 출력한다. 실행결과는 아래와 같다.</p>
<blockquote data-ke-style="style3">1번 학생은 Pass입니다.<br />2번 학생은 재수강입니다.<br />3번 학생은 재수강입니다.<br />4번 학생은 재수강입니다.<br />5번 학생은 Pass입니다.</blockquote>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#for문과 continue문</h4>
<p data-ke-size="size16">while문에서 보았던 continue문을 for문에서도 사용할 수 있다. 즉 for문 안의 문장을 수행하는 도중에 continue문을 만나면 for문의 처음으로 돌아가게 된다.</p>
<p data-ke-size="size16">앞에서 사용한 for문 코드를 그대로 가져와서 80점 이상인 사람에게는 축하 메시지를 보내고 나머지 사람에게는 아무 메시지도 전하지 않는 프로그램을 만들어보자.</p>
<blockquote data-ke-style="style3">student = [100, 50, 77, 67, 90]<br />number = 0<br />for socre in student:<br />&nbsp; &nbsp; &nbsp; number = number + 1<br />&nbsp; &nbsp; &nbsp; if socre &lt; 80: continue<br />&nbsp; &nbsp; &nbsp; print("%d번 학생 축하합니다. Pass입니다." % number)</blockquote>
<p data-ke-size="size16">점수가 80점 미만인 학생일 경우 score &lt; 80이 참이 되어 continue문이 수행된다. 따라서 축하 메시지를 출력하는 부분인 print문을 수행하지 않고 for문의 처음으로 돌아가게 된다.</p>
<blockquote data-ke-style="style3">1번 학생 축하합니다. Pass입니다.<br />5번 학생 축하합니다. Pass입니다.</blockquote>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#for문과 함께 자주 사용하는 range 함수</h4>
<p data-ke-size="size16">for문은 숫자 리스트를 자동으로 만들어 주는 range 함수와 함께 사용하는 경우가 많다. 아래는 range 함수의 간단한 사용법이다.</p>
<p data-ke-size="size16">range(10)은 0부터 10 미만의 숫자를 포함하는 range 객체를 만들어 준다.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; a = range(10)<br />&gt;&gt;&gt; a<br />range(0, 10)</blockquote>
<p data-ke-size="size16">시작 숫자와 끝 숫자를 지정하려면 range(시작 숫자, 끝 숫자) 형태를 사용하는데, 이때 끝 숫자는 포함되지 않는다.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; a = range(1, 11)<br />&gt;&gt;&gt; a<br />range(1, 11)</blockquote>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#range 함수 톺아보기</h4>
<p data-ke-size="size16">이번엔 range 함수에 대해 더 자세하게 알아보자.</p>
<p data-ke-size="size16">먼저 for와 range 함수를 사용하여 1부터 10까지 더해보자. 아래와 같이 코드를 구성하면 된다.</p>
<p data-ke-size="size16">range(1,11)은 숫자 1부터 10까지(1이상 11미만)의 숫자를 데이터로 갖는 객체이다. 따라서 i 변수에 리스트의 숫자가 1부터 10까지 하나씩 차쳬로 대입되면서 add = add + i 문장을 반복적으로 수행하고 add는 최종적으로 55가 된다.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; add = 0<br />&gt;&gt;&gt; for i in range(1, 11):<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;add = add + i<br />&gt;&gt;&gt; print(add)<br />55</blockquote>
<p data-ke-size="size16">이번엔 for문 코드를 알아보며 사용했던 '80점 이상이면 Pass'이라는 문장을 출력하는 예시도 range 함수를 사용할 수 있다.</p>
<p data-ke-size="size16">아래 코드에서는 number 변수에 차례로 0부터 4까지의 숫자가 대입될 것이고, marks[number]는 차례대로 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">100, 50, 77, 67, 90 값을 갖게 된다. 결과는 이전에 사용했던 코드의 결괏값과 동일하다.</span></p>
<blockquote data-ke-style="style3">student = [100, 50, 77, 67, 90]<br />for socre in range(len(student)):<br />&nbsp; &nbsp; &nbsp; if student[number] &lt; 80: continue<br />&nbsp; &nbsp; &nbsp; print("%d번 학생 축하합니다. Pass입니다." % (numbe+1))</blockquote>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#for와 range 활용해보기</h4>
<p data-ke-size="size16">이번엔 for와 range를 활용하여 구구단을 출력하는 코드를 짜볼려고 한다. 학창시절 학교에서 파이썬을 배울때면 항상 쳐봤던 코드라 개인적으로 익숙했다. 코드는 아래와 같다.</p>
<p data-ke-size="size16">아래 코드를 보면 for문이 두 번 사용되었다. 먼저&nbsp; 첫 번째 for문에서 2부터 9까지의 숫자(range(2, 10))가 차례로 i에 대입된다. i가 처음 2일 때 두 번째 for문을 만나게 된다. 두 번째 for문에서 1부터 9까지의 숫자(rnage(1,10))가 j에 대입되고 그다음 문장 print(i*j)를 수행하게 된다. 따라서 i가 2일 때 2*1, 2*2, 2*3, ... , 2*9까지 차례로 수행한 뒤 그 값을 출력하게 된다. 이후 i가 3일 때 역시 이와 같이 수행되며 반복된다. 또한 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">print(i*j, end=" ")이 부분에서 end를 왜 넣었을지 궁금할 수 있다. 그 이유는 해당 결괏값을 출력할 때 다음줄로 넘기지 않고 그 줄에 계속해서 출력하기 위해서이다. 이후 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">print(' ')를 통해 구구단의 각 단을 구분하기 위해 두 번째 for문이 끝나면 결괏값을 다음 줄부터 출력하게 해준다.</span></span></p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; for i in range(2,10):<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;for j in range(1,10):<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; print(i*j, end=" ")<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;print(' ')<br /><br />2 4 6 8 10 12 14 16 18<br />3 6 9 12 15 18 21 24 27<br />...</blockquote>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#리스트 내포 사용하기</h4>
<p data-ke-size="size16">리스트 안에 for문을 포함하는 리스트 내포(List comprehension)를 사용해보자.</p>
<p data-ke-size="size16">아래 코드는 a 리스트의 각 항목에 3을 곱한 겨로가를 result 리스트에 담는 코드이다.&nbsp;</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; a = [1,2,3,4]<br />&gt;&gt;&gt; result = []<br />&gt;&gt;&gt; for num in a:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; result.append(num*3)<br />&gt;&gt;&gt; print(result)<br />[3, 6, 9, 12]</blockquote>
<p data-ke-size="size16">위 코드를 한번 리스트 내포를 사용해보자. 코드는 아래와 같다.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; a = [1,2,3,4]<br />&gt;&gt;&gt; result = [num*3 for num in a]<br />&gt;&gt;&gt; print(result)<br />[3, 6, 9, 12]</blockquote>
<p data-ke-size="size16">만약 [1,2,3,4] 중 짝수에만 3을 곱하여 담고 싶다면 아래와 같이 리스트 내포 안에 'if 조건'을 사용할 수 있다.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; a = [1,2,3,4]<br />&gt;&gt;&gt; result = [num*3 for num in a if num % 2 == 0]<br />&gt;&gt;&gt; print(result)<br />[6, 12]</blockquote>
<p data-ke-size="size16">리스트 내포의 일반 문법은 아래와 같다. 'if 조건' 부분은 생략 가능하다.</p>
<blockquote data-ke-style="style3">[표현식 for 항목 in 반복 가능 객체 if 조건]</blockquote>
<p data-ke-size="size16">여기서 for문을 2개 이상 사용도 가능하다. for문을 여러 개 사용할 때의 문법은 아래와 같다.</p>
<blockquote data-ke-style="style3">[표현식 for 항목1 in 반복 가능 객체1 if 조건1<br />for 항목2 in 반복 가능 객체2 if 조건2<br />for 항목3 in 반복 가능 객체3 if 조건3<br />... <br />for 항목n in 반복 가능 객체n if 조건n<br />]</blockquote></div>
