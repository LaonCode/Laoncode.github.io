            <div class="contents_style"><p data-ke-size="size16">프로그램의 입력과 출력은 어떻게 해야할까?</p>
<p data-ke-size="size16">지금까지 공부한 내용을 바탕으로 함수, 입력과 출력, 파일 처리 방법 등을 알아보려고 한다.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#함수 톺아보기</h4>
<p data-ke-size="size16">함수라는 단어는 학창시절 수학시간에 매번 들어봤을 것이다. 아마 아래에 있는 그림과 함께 함수를 이해했을 것이다. 프로그램에서의 함수도 비슷하다. 입력값을 가지고 어떤 일을 수행한 다음에 그 결과물을 내어놓는 것이 바로 함수이다.</p>
<p><figure class="imageblock alignCenter" data-ke-mobileStyle="widthOrigin" data-origin-width="435" data-origin-height="201"><span data-url="/assets/images/posts/dd7de22a99c57672085194928a4d9c97cd7d478a.gif" data-phocus="/assets/images/posts/dd7de22a99c57672085194928a4d9c97cd7d478a.gif"><img src="/assets/images/posts/dd7de22a99c57672085194928a4d9c97cd7d478a.gif" loading="lazy" width="435" height="201" data-origin-width="435" data-origin-height="201"/></span></figure>
</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#우리는 함수를 왜 사용할까?</h4>
<p data-ke-size="size16">프로그래밍을 하다 보면 똑같은 내용을 반복해서 작성하고 있는 경우가 있을 것이다. 이럴때마다 힘들고 복잡하게 느껴질 것이다. 이럴때 바로 함수가 필요하다. 즉 반복되는 부분이 있을 경우 '반복저으로 사용되는 가치 있는 부분'을 한 뭉치로 묶어서 '어떤 입력밧을 주었을 때 어떤 결괏값을 돌려준다'라는 식의 함수로 작성하는 것이 현명하다.</p>
<p data-ke-size="size16">함수를 사용하는 또 다른 이유는 자신이 만든 프로그램을 함수화하면 프로그램 흐름을 한눈에 볼 수 있기 때문이다. 마치 공장에서 원재료가 여러 공정을 거쳐 하나의 상품이 되는 것처럼 프로그램에서도 입력한 값이 여러 함수를 거치면서 원하는 결괏값을 내는 것을 볼 수 있다. 이렇게 되면 프로그램 흐름도 잘 파악할 수 있고 오류가 어디서 나는지도 바로 알 수 있다.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#파이썬 함수의 구조</h4>
<p data-ke-size="size16">파이썬 함수의 구조는 아래와 같다. def는 함수를 만들 때 사용하는 예약어이며, 함수 이름은 함수를 만드는 사람이 임의로 만들 수 잇다. 함수 이름 뒤 괄호 안의 매개변수는 이 함수에 입력으로 전달되는 값을 받는 변수이다. 이렇게 함수를 정의한 다음 if, while, for문 등과 마찬가지로 함수에서 수행할 문장을 입력한다.</p>
<blockquote data-ke-style="style3">def 함수 이름(매개 변수):<br />&nbsp; &nbsp; &nbsp; 수행할 문장1<br />&nbsp; &nbsp; &nbsp; 수행할 문장2<br />&nbsp; &nbsp; &nbsp; ...</blockquote>
<p data-ke-size="size16">한번 예시를 살펴보자.</p>
<blockquote data-ke-style="style3">def add(a, b):<br />&nbsp; &nbsp; &nbsp; return a + b</blockquote>
<p data-ke-size="size16">이 함수는 아래와 같이 풀이된다.</p>
<blockquote data-ke-style="style3">이 함수의 이름(함수 이름)은 add이고 입력으로 2개의 값을 받으며 결괏값은 2개의 입력값을 더한 값이다.</blockquote>
<p data-ke-size="size16">여기서 return은 함수의 결괏값을 돌려주는 명령어이다. 먼저 아래와 같이 add 함수를 만들자.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; def add(a, b):<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; return a + b<br />&gt;&gt;&gt;</blockquote>
<p data-ke-size="size16">이제 add 함수를 사용해 볼까?</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; a = 3<br />&gt;&gt;&gt; b = 4<br />&gt;&gt;&gt; c = add(a, b)<br />&gt;&gt;&gt; print(c)<br />7</blockquote>
<p data-ke-size="size16">변수 a에 3, b에 4를 대입한 다음 앞에서 만든 add 함수에 a와 b를 입력값으로 넣어 준다. 그리고 변수 c에 add 함수의 결괏값을 대입하면 print(c)로 c의 값을 확인할 수 있다.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#매개변수와 인수</h4>
<p data-ke-size="size16">매개변수(parameter)와 인수(arguments)는 혼용해서 사용되는 헷갈리는 용어이다. 매개변수는 함수에 입력으로 전달된 값을 받는 변수를 의미하고 인수는 함수를 호출할 때 전달하는 입력값을 의미한다.</p>
<blockquote data-ke-style="style3">def add(a, b):<br />&nbsp; &nbsp; &nbsp; return a + b<br /><br />print(add(3, 4))</blockquote>
<p><figure class="imageblock alignCenter" data-ke-mobileStyle="widthOrigin" data-origin-width="916" data-origin-height="189"><span data-url="/assets/images/posts/ce53a774c5845483f6b945e78847f3885fe955d4.png" data-phocus="/assets/images/posts/ce53a774c5845483f6b945e78847f3885fe955d4.png"><img src="/assets/images/posts/ce53a774c5845483f6b945e78847f3885fe955d4.png" loading="lazy" width="916" height="189" data-origin-width="916" data-origin-height="189"/></span></figure>
</p>
<blockquote data-ke-style="style1"><span style="font-family: 'Noto Serif KR';">이렇게 2주차가 마무리 되었다. 1주차에서 파이썬이 무엇인지 배웠다면, 2주차에는 이제 어떻게 활용하고 사용하는지 배워본 것 같다. 다행히 반복문과 함수는 이전에도 들어보고 사용해본적이 있어서 나름 비교적 수월하게 한 것 같다.<br /></span>다음주에 있을 3주차를 기대하며..END</blockquote></div>
