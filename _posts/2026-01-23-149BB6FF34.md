            <div class="contents_style"><h4 style="color: #000000; text-align: start;" data-ke-size="size20">#클래스 톺아보기</h4>
<p data-ke-size="size16">우리가 파이썬 이외에 많이 알고 있는 프로그래밍 언어 중 하나인 C언어는 클래스라는 것이 없다. 그 이유는 클래스가 없어도 프로그램을 충분히 만들 수 있기 때문이다. 실제로 파이썬으로 잘 만들어진 프로그램 중에도 클래스를 사용하지 않고 작성한 것들이 상당히 많고, 함수나 자료형처럼 프로그램 작성을 위해 꼭 필요한 요소는 아니다. 하지만 프로그램을 작성할 대 클래스를 잘 사용하면 프로그램을 만들 때 얻을 수 있는 이익이 많다. 한번 계산기를 떠올려 보자. 우리가 2+3을 계산기로 계산한다고 한다면 계산기에 숫자 2를 입력하고 + 기호를 입력한 후 3을 입력하면 결괏값으로 5를 보여 준다. 다시 한번 + 기호를 입력한 후 5를 입력하면 기존 결괏값 5에 5를 더해 10을 보여 준다. 즉 계산기는 이전에 계산한 결괏값을 항상 메모리 어딘가에 저장하고 있어야 한다.</p>
<p data-ke-size="size16">그럼 파이썬을 코드를 통해 계산기의 '더하기' 기능을 구현해보자.</p>
<p data-ke-size="size16">이전에 계산한 결괏값을 유지하기 위해서 result 전역 변수(global)를 사용했다.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; result = 0<br /><br />&gt;&gt;&gt; def add(num):<br />&nbsp; &nbsp; &nbsp; global result<br />&nbsp; &nbsp; &nbsp; result += num<br />&nbsp; &nbsp; &nbsp; return result<br /><br />&gt;&gt;&gt; print(add(2))<br />2<br />&gt;&gt;&gt;<br />print(add(3))<br />5</blockquote>
<p data-ke-size="size16">그런데 만약 한 프로그램에서 2대의 계산기가 필요한 상황이 발생하면 어떨까?</p>
<p data-ke-size="size16">각 계산기는 각각의 결괏값을 유지해야 하기 때문에 add 함수 하나만으로는 결괏값을 따로 유지할 수 없다.</p>
<p data-ke-size="size16">이런 상황에서는 아래와 같이 함수를 각각 다로 만들어야 한다.</p>
<p data-ke-size="size16">똑같은 일을 하는 add1과 add2 함수를 만들었고 각 함수에서 계산한 결괏값을 유지하면서 저장하는 전역 변수 result1, result2가 필요하게 되었다.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; result1 = 0<br />&gt;&gt;&gt; result2 = 0<br /><br />&gt;&gt;&gt; def add1(num):<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; global result1<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; result1 += num<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; return result1<br /><br />&gt;&gt;&gt; def add2(num):<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; global result2<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; result2 += num<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; return result2<br /><br />&gt;&gt;&gt; print(add1(2))<br />2<br />&gt;&gt;&gt;<br />print(add1(3))<br />5<br />&gt;&gt;&gt; print(add2(1))<br />1<br />&gt;&gt;&gt;<br />print(add2(2))<br />3</blockquote>
<p data-ke-size="size16">계산기 1의 결괏값이 계산기 2에 아무 영향을 끼치지 않는 것을 확인할 수 있다.</p>
<p data-ke-size="size16">하지만 계산기가 2개가 아닌 수십 개가 필요하다면 어떻게 해야 할까? 그때마다 전역 변수와 함수를 추가하기에는 너무 힘들 것이다. 만약 빼거나 곱하는 등의 기능이 추가로 필요하다면 막막해질 것이다. 이런 경우에 사용하는 것이 클래스이다.</p>
<p data-ke-size="size16">한번 클래스를 활용해 보자. 코드는 아래와 같다.</p>
<blockquote data-ke-style="style3">class Calcularor:<br />&nbsp; &nbsp; &nbsp;def __init__(self):<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; self.result = 0<br /><br />&nbsp; &nbsp; &nbsp;def add(self, num):<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; self.result += num<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; return self.result<br /><br />cal1 = Calculator()<br />cal2 = Calculator()<br /><br />&gt;&gt;&gt; print(cal1.add1(2))<br />2<br />&gt;&gt;&gt;<br />print(cal1.add1(3))<br />5<br />&gt;&gt;&gt; print(cal2.add2(1))<br />1<br />&gt;&gt;&gt;<br />print(cal2.add2(2))<br />3</blockquote>
<p data-ke-size="size16">Calculator 클래스로 만든 별개의 계산기 cal1, cal2(파이썬에서는 이것을 객체라고 부른다.)가 각각의 역할을 수행한다. 그리고 계산기(cal1, cal2)의 결괏값 역시 다른 계산기의 결괏값과 상관없이 독립적인 값을 유지한다. 클래스를 사용하면 계산기 대수가 늘어나더라도 객체를 생성만 하면 되기 때문에 함수를 사용하는 경우와 달리 매우 간단해진다.</p>
<blockquote data-ke-style="style3">def sub(self, num):<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; self.result -= num<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; return self.result</blockquote>
