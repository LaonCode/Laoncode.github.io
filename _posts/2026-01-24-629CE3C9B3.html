#모듈 톺아보기

모듈이란 무엇일까?

모듈이란 함수나 변수 또는 클래스를 모아 놓은 파일이다.

모듈은 다른 파이썬 프로그램에서 불러와 사용할 수 있게 만든 파이썬 도라에몽 주머니라고 할 수 있을 것 같다. 파이썬으로 프로그래밍을 할 때 굉장히 많은 모듈을 사용한다. 다른 사람들이 이미 만들어 놓은 모듈을 사용할 수도 있고 우리가 직접 만들어서 사용할 수도 있다. 이제부터 모듈을 어떻게 만들고 사용하는지 알아보자.

#모듈 만들기

모듈에 대해 자세히 알아보기 전에 간단한 모듈을 한번 만들어 보자.

아래와 같이 add와 sub 함수만 있는 파일 mod.py를 만들고 C:\spactcode 디렉터리에 저장하였다. 이 mod.py 파일이  바로 모듈이다.

def add(a, b):
      return a + b

def sub(a, b)
      return a - b

#모듈 불러오기

방금 만든 mod.py 파일, 즉 모듈을 파이썬에서 불러와 사용하려면 어떻게 해야할까?

먼저 명령어 프롬프트(CMD) 창을 열고 mod.py를 저장한 디렉터리로 이동한 다음 대화형 인터프리터를 실행한다.

C:\Users\spact>cd C:\spactcode
C:\spactcode>dir
2026-01-24 오후 05:50 32 mod.py

C:\spactcode> python
>>>

이제 아래와 같이 입력해보자.

>>> import mod
>>> print(mod.add(2,3))
5
>>> print(mod.sub(5,2))
3

mod.py를 불러오기 위해 import mod이라고 입력하였다.

import는 이미 만들어 놓은 파이썬 모듈을 사용할 수 있게 해주는 명령어이다. mod.py 파일에 있느 ㄴㅁdd 함수르 사용하기 위해서는 위 코드와 같이 mod.add처럼 모듈 이름 뒤에 '.'(도트 연산자)를 붙이고 함수 이름을 쓰면 된다.

import의 사용 방법은 아래와 같다.

여기서 모듈 이름은 mod.py에서 .py 확장자를 제거한 mod만을 가리킨다.

import 모듈 이름

하지만 가끔은 mod.add, mod.sub처럼 쓰지 않고 add, sub처럼 모듈 이름 없이 함수 이름만 쓰고 싶을 수도 있다. 이런 경우 'form 모듈 이름 import 모듈 함수'를 사용하면 된다.

from 모듈 이름 import 모듈 함수

위 형식을 사용하면 모듈 이름을 붙이지 않고 바로 해당 모듈의 함수를 쓸 수 있다.

>>> from mod import add
>>> add(2,3)
5

그런데 위와 같이 하면 mod.py 파일의 add함수만 사용할 수 있다. add 함수와 sub 함수를 둘 다 사용하기 위해서는 2가지 방법이 있다.

첫 번째 방법은 아래오 ㅏ같이 form 모듈 이름 import 모듈 함수1, 모듈 함수2 처럼 사용하는 것이다. 콤마로 구분하여 필요한 함수를 불러올 수 있다

from mod inport add, sub

두 번째 방법은 아래와 같이 * 문자를 사용하는 방법이다. 여기서 * 문자는 '모든 것' 즉 All 이라는 뜻이다. 따라서 from mod import *는 mod.py의 모든 함수를 불러서 사용하겠다는 뜻이다.

from mod inport *
