            <div class="contents_style"><p data-ke-size="size16">프로그램을 만들다 보면 우리는 매 순간 오류와 마주친다. 하지만 때때로 이 오류를 무시하고 싶을 때도 있다. 이를 위해 파이썬은 try, except를 사용해서 예외적으로 오류를 처리할 수 있게 해 준다.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#오류는 어떤 경우에 발생할까?</h4>
<p data-ke-size="size16">오류를 처리하기 전에 오류가 어떤 상황에 발생하는지 알아보자.</p>
<p data-ke-size="size16">먼저 디렉터리 안에 없는 파일을 열려고 시도했을 때 발생하는 오류부터 살펴보려고 한다. 아래 코드와 오류에서 볼 수 있듯이 없는 파일을 열려고 시도하면 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">FileNotFoundError 오류가 발생한다.</span></p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; f = open("난 파일입니다", 'r') <br />Traceback (most recent call last):<br />&nbsp; &nbsp; &nbsp; File "&lt;python-input-0&gt;", line 1, in &lt;module&gt; <br />&nbsp; &nbsp; &nbsp; f = open("난 파일입니다", 'r') <br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;~~~~^^^^^^^^^^^^^^^^^^<br />FileNotFoundError: [Errno 2] No such file or directory: '난 파일입니다'</blockquote>
<p data-ke-size="size16"><span style="color: #333333; text-align: start;">위 코드와 오류에서 볼 수 있듯이 없는 파일을 열려고 시도하면<span>&nbsp;</span></span><span style="background-color: #fcfcfc; color: #666666; text-align: left;">FileNotFoundError 오류가 발생한다.</span></p>
<p data-ke-size="size16">이번에는 0으로 다른 숫자를 나눠보는 경우는 어떨까?</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; 3/0 <br />Traceback (most recent call last): <br />&nbsp; &nbsp; &nbsp;File "&lt;python-input-1&gt;", line 1, in &lt;module&gt; <br />&nbsp; &nbsp; &nbsp; &nbsp;3/0 <br />&nbsp; &nbsp; &nbsp; ~^~ <br />ZeroDivisionError: division by zero</blockquote>
<p data-ke-size="size16">3을 0으로 나누려고 시도를 하니 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">ZeroDivisionError 오류가 발생한다.</span></p>
<p data-ke-size="size16"><span style="background-color: #fcfcfc; color: #666666; text-align: left;">마지막으로 오류 한 가지 더 살펴보자.</span></p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; a = [3, 6, 9] <br />&gt;&gt;&gt; a[5] <br />Traceback (most recent call last): <br />&nbsp; &nbsp; &nbsp;File "&lt;python-input-3&gt;", line 1, in &lt;module&gt; <br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; a[5] <br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; ~^^^ <br />IndexError: list index out of range</blockquote>
<p data-ke-size="size16"><span style="background-color: #fcfcfc; color: #666666; text-align: left;">a는 리스트 [3, 6, 9]이다. 그렇기 때문에 a[5]는 a 리스트에서 얻을 수 없는 값이다. 따라서 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">IndexError 오류가 발생한 것이다. 파이썬은 이런 오류가 발생하면 프로그램을 중단하고 오류 메시지를 보여 준다.</span></span></p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#오류 예외 처리 기법</h4>
<p data-ke-size="size16">이제 오류 처리 기법에 대해 살펴보도록 하자.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.1 try, except문</h4>
<p data-ke-size="size16">아래는 오류 처리를 위한 try, except문의 기본 구조이다. try 블록 수행 중 오류가 발생하면 except 블록이 수행된다. 하지만 try 블록에서 오류가 발생하지 않는다면 except 블록은 수행되지 않는 구조이다.</p>
<blockquote data-ke-style="style3">try:<br />&nbsp; &nbsp; &nbsp;...<br />except [발생 오류[as 오류 메시지 변수]]:<br />&nbsp; &nbsp; &nbsp;...</blockquote>
<p data-ke-size="size16"><span style="color: #333333; text-align: start;">except 구문은 조금 특이해 보인다. 한번 자세하게 살펴보자.</span></p>
<blockquote data-ke-style="style3">except [발생 오류[as 오류 메시지 변수]]:</blockquote>
<p data-ke-size="size16">위 구문을 보면 [ ] 기호를 사용하고 있다. 이 기호는 괄호 안의 내용을 생략할 수 있다는 관례 표기법이다. 즉 except 구문은 다음 3가지 방법으로 사용할 수 있다.</p>
<p data-ke-size="size16">1. try, except만 쓰는 방법</p>
<p data-ke-size="size16">이 경우는 오류 종류에 상관없이 오류가 발생하면 except 블록을 수행한다.</p>
<blockquote data-ke-style="style3">try:<br />&nbsp; &nbsp; &nbsp;...<br />except:<br />&nbsp; &nbsp; &nbsp;...</blockquote>
<p data-ke-size="size16">2. 발생 오류만 포함한 execpt문</p>
<p data-ke-size="size16">이 경우 오류가 발생했을 때 except문에 미리 정해 놓은 오류 이름과 일치할 때만 except 블록을 수행한다는 뜻이다.</p>
<blockquote data-ke-style="style3">try:<br />&nbsp; &nbsp; &nbsp;...<br />except 발생 오류 as 오류 메시지 변수:<br />&nbsp; &nbsp; &nbsp;...</blockquote>
<p data-ke-size="size16">이 방법의 예를 한번 살펴보자.</p>
<blockquote data-ke-style="style3">try:<br />&nbsp; &nbsp; &nbsp;3/0<br />except 발생 오류 as 오류 메시지 변수:<br />&nbsp; &nbsp; &nbsp;print(e)</blockquote>
<p data-ke-size="size16">위 코드처럼 3을 0으로 나누려고 하면 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">ZeroDivisionError가 발생하여 except 블록이 실행되고 변수 e에 담기는 오류 메시지를 아래와 같이 출력한다.</span></p>
<blockquote data-ke-style="style3">결괏값: division by zero</blockquote>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.2 try ...finally</h4>
<p data-ke-size="size16">try문에는 finally절을 사용할 수 있다. finally절은 try문 수행 도중 예외 발생 여부에 상관없이 항상 수행된다. 보통 finally절은 사용한 리소스를 close 해야 할 때에 많이 사용한다. 아래 예시를 살펴보자.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; f = open('finally.txt', 'w')<br />&gt;&gt;&gt; try:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;#수행할 코드<br />&gt;&gt;&gt; finally:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; f.close()</blockquote>
<p data-ke-size="size16">finally.txt 파일을 쓰기 모드로 연 후에 try문을 수행한 후 예외 발생 여부와 상관없이 finally절에서 f.close()로 열린 파일을 닫을 수 있다.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.3 여러 개의 오류 처리하기</h4>
<p data-ke-size="size16">try문 안에서 여러 개의 오류를 처리하기 위해 아래와 같은 구문을 사용한다.</p>
<blockquote data-ke-style="style3">try:<br />&nbsp; &nbsp; ...<br />except 발생 오류1:<br />&nbsp; &nbsp; ...<br />except 발생 오류2:<br />&nbsp; &nbsp; ...</blockquote>
<p data-ke-size="size16">즉 0으로 나누는 오류와 인덱싱 오류를 아래와 같이 처리할 수 있다.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; try:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;a = [3, 7]<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;print(a[5])<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;3/0<br />&gt;&gt;&gt; except ZeroDivisionError:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;print("0으로 나눌 수 없습니다.")<br />&gt;&gt;&gt; except IndexError:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;print("인덱싱할 수 없습니다.")</blockquote>
<p data-ke-size="size16">a는 2개의 요솟값을 가지고 있기 때문에 a[5]는 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">IndexError를 발생시키므로 ' <span style="background-color: #fcfcfc; color: #666666; text-align: left;">인덱싱할 수 없습니다.'라는 물자열이 출력될 것이다. 인덱싱 오류가 먼저 발생했으므로 3/0으로 발생되는 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">ZeroDivisionError 오류는 발생하지 않았다.</span></span></span></p>
<p data-ke-size="size16"><span style="background-color: #fcfcfc; color: #666666; text-align: left;"><span style="background-color: #fcfcfc; color: #666666; text-align: left;"><span style="background-color: #fcfcfc; color: #666666; text-align: left;">아래와 같이 작성한다면 오류 메시지도 다음과 같이 가져올 수 있다.</span></span></span></p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; try:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; a = [3, 7]<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; print(a[5])<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 3/0<br />&gt;&gt;&gt; except ZeroDivisionError as e:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;print(e)<br />&gt;&gt;&gt; except IndexError as e:<br />&nbsp; &nbsp; &nbsp; print(e)</blockquote>
<p data-ke-size="size16">프로그램을 실행하면 list index out of range 오류 메시지가 출력될 것이다.</p>
<p data-ke-size="size16">다음과 같이 ZerroDivisionError와 IndexError를 함께 처리할 수도 있다.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; try:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; a = [3, 7]<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; print(a[5])<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; 3/0<br />&gt;&gt;&gt; except (ZeroDivisionError, IndexError) as e:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;print(e)</blockquote>
<p data-ke-size="size16">2개 이상의 오류를 동시에 처리하기 위해서는 위와 같이 괄호를 사용하여 함께 묶어 처리하면 된다.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20"># 오류 회피하기</h4>
<p data-ke-size="size16">코드를 짜다보면 특정 오류가 발생할 경우 그냥 통과시켜야 할 때가 있다. 아래 예를 살펴보자.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; try:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;f = open("난 파일입니다", 'r')<br />&gt;&gt;&gt; except FileNotFoundError:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; pass</blockquote>
<p data-ke-size="size16">try문 안에서 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">FileNotFoundError가 발생할 경우 pass를 사용하여 오류를 그냥 회피하도록 작성한 것이다.</span></p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20"># 오류 일부러 발생시키기</h4>
<p data-ke-size="size16">뭔가 이상할 수도 있지만 프로그래밍을 하다 보면 가끔씩 오류를 일부러 발생시켜야 할 경우도 생긴다. 파이썬은 raise 명령어를 사용해 오류를 강제로 발생시킬 수 있다.</p>
<p data-ke-size="size16">예를 들어 Bird 클래스를 상속받는 자식 클래스는 반드시 fly라는 함수를 구현하도록 만들고 싶은 경우(강제로 그렇게 하고 싶은 경우)가 있을 수 있다. 아래 예시를 한번 살펴보자.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; class Bird:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; def fly(self):<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; raise NotImplementedError</blockquote>
<p data-ke-size="size16">위 예시는 Bird 클래스를 상속받는 자식 클래스를 반드시 fly 함수를 구현해야 한다는 의지를 보여 준다. 만약 자식 클래스가 fly 함수를 구현하지 않은 상태로 fly 함수를 호출한다면 어떻게 될지 살펴보자.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; class Eagle(Bird):<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; pass<br />eagle = Eagle()<br />eagle.fly()</blockquote>
<p data-ke-size="size16"><span style="background-color: #fcfcfc; color: #666666; text-align: left;">Eagle 클래스는 Bird 클래스를 상속받는다. 그런데 Eagle 클래스에서 fly 함수를 구현하지 않았기 때문에 Bird 클래스의 fly 함수가 호출된다. 또한 raise문에 의해 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">NotImplemented Errorrk(파이썬 내장 오류로, 꼭 작성해야 하는 부분이 구현되지 않았을 경우 일부러 오류를 일으키기 위해 사용한다.)가 발생할 것이다.(상속받는 클래스에서 함수를 재구현하는 것을 메서드 오버라이딩이라고 부른다.)</span></span></p>
<blockquote data-ke-style="style3">Traceback (most recent call last):<br />&nbsp; &nbsp; File "&lt;python-input-0&gt;", line 8, in &lt;module&gt; <br />&nbsp; &nbsp; &nbsp; &nbsp; eagle.fly() <br />&nbsp; &nbsp; &nbsp; &nbsp;~~~~~~~^^ <br />File "&lt;python-input-0&gt;", line 3, in fly <br />&nbsp; &nbsp;raise NotImplementedError<br />NotImplementedError</blockquote>
<p data-ke-size="size16"><span style="background-color: #fcfcfc; color: #666666; text-align: left;">NotImplementedError가 발생되지 않게 하려면 아래와 같이 Eagle 클래스에 fly 함수를 반드시 구현해야 한다.</span></p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; class Eagle(Bird):<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;def fly(self):<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; print("Error NO!!")<br />eagle = Eagle()<br />eagle.fly()</blockquote>
<p data-ke-size="size16">위 예시처럼 fly 함수를 구현한 후 프로그램을 실행하면 오류 없이 아래와 같은 문장이 출력된다.</p>
<blockquote data-ke-style="style3">Error NO!!</blockquote>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20"># 예외 만들기</h4>
<p data-ke-size="size16">프로그램 수행 도중 특수한 경우에만 예외 처리를 하기 위해서 종종 예외를 만들어서 사용한다.&nbsp;</p>
<p data-ke-size="size16">이번에는 한번 예외를 직접 만들어 보려고 한다. 예외는 아래와 같이 파이썬 내장 클래스인 Exception 클래스를 상속하여 만들 수 있다.</p>
<blockquote data-ke-style="style3">class MyError(Exception):<br />&nbsp; &nbsp; &nbsp; pass</blockquote>
<p data-ke-size="size16">그리고 별명을 출력해 주는 함수를 아래와 같이 작성한다.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; def say_nick(nick):<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;if nick == '견우':<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; raise MyError()<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;print(nick)</blockquote>
<p data-ke-size="size16">한번 say_nick 함수를 호출해 보자. 프로그램을 실행해 보면 아래와 같이 '견우'가 한 번 출력된 후 MyError가 발생한다.</p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; say_nick("견우")<br />직녀<br />&gt;&gt;&gt; say_nick("직녀")<br />Traceback (most recent call last): <br />&nbsp; &nbsp; &nbsp;File "&lt;python-input-3&gt;", line 1, in &lt;module&gt; <br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; say_nick("견우") <br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; ~~~~~~^^^^^^^^ <br />&nbsp; &nbsp; &nbsp;File "&lt;python-input-1&gt;", line 3, in say_nick <br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp;raise MyError() <br />MyError</blockquote>
<p data-ke-size="size16">이번에는 예외 처리 기법을 사용하여 MyError 발생을 예외 처리해 보자.</p>
<blockquote data-ke-style="style3">try:<br />&nbsp; &nbsp; say_nick("직녀") <br />&nbsp; &nbsp; say_nick("견우")<br />except MyError:<br />&nbsp; &nbsp; &nbsp;print("허용되지 않는 별명입니다.")</blockquote>
<p data-ke-size="size16">프로그램을 실행하면 아래와 같이 출력된다.(이때 try문에서 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">say_nick("직녀")와 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">say_nick("견우")의 순서를 바꾸면 허용되지 않는 별명입니다. 결과만 출력된다.)</span></span></p>
<blockquote data-ke-style="style3">직녀<br />허용되지 않는 별명입니다.</blockquote>
<p data-ke-size="size16">만약 오류 메시지를 사용하고 싶다면 아래처럼 예외 처리를 하면 된다.</p>
<blockquote data-ke-style="style3">try:<br />&nbsp; &nbsp; say_nick("직녀")<br />&nbsp; &nbsp; say_nick("견우")<br />except MyError as e:<br />&nbsp; &nbsp; &nbsp;print(e)</blockquote>
<p data-ke-size="size16">하지만 프로그램을 실행하면 print(e)로 오류 메시지가 출력되지 않는 것을 확인할 수 있다. 오류 메시지를 출력했을 대 오류 메시지가 보이게 하려면 오류 클래스에 아래와 같은 __str__메서드를 구현해야 한다. __str__메서드는 print(e)처럼 오류 메시지를 print문으로 출력할 경우에 호출되는 메서드이다.</p>
<blockquote data-ke-style="style3">class MyError(Excption):<br />&nbsp; &nbsp; &nbsp;def __str__(self):<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; return "허용되지 않는 별명입니다."</blockquote>
<p data-ke-size="size16">프로그램을 실행해 보면 "허용되지 않는 별명입니다."라는 오류 메시지가 출력되는 것을 확인할 수 있다.</p></div>
