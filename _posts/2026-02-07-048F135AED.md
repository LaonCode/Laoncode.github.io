            <div class="contents_style"><h4 style="color: #000000; text-align: start;" data-ke-size="size20">#구구단 만들기</h4>
<p data-ke-size="size16">이번에는 정말 프로그램을 짜보려고 한다. 점프 투 파이썬에서는 파이썬 문법도 다 공부한 사람이 프로그램을 어떻게 만들어야 할지 갈피를 못잡는 사람에게 아래와 같은 해결책을 제시해주었다.</p>
<blockquote data-ke-style="style3">프로그램을 만들려면 가장 먼저 '입력'과 '출력'을 생각하라.</blockquote>
<p data-ke-size="size16">만약 구구단 프로그램 중 3단을 만든다면 3을 입력값으로 주었을 때 어떻게 출력되야될까? 한번 어떻게 만들어야할지 생각을 적어보자.</p>
<blockquote data-ke-style="style3">함수의 이름은 times라고 하자.<br />3를 입력값으로 받자.<br />출력값은 3단이니 3, 6, 9, 12, 15, 18,..., 27이 되겠다.<br />결과는 연속된 자료형이니 리스트로 저장하자.</blockquote>
<p data-ke-size="size16">그럼 이 생각을 바탕으로 한번 코드를 짜보도록 하자.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.1 함수 만들기</h4>
<p data-ke-size="size16">먼저 함수의 이름은 times라고 하기로 하였다. 그렇다면 times라는 함수에 3을 입력값으로 주면 result라는 변수에 결괏값을 넣도록 만들자.</p>
<blockquote data-ke-style="style3">result = times(3)</blockquote>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.2 결괏값 생각하기</h4>
<p data-ke-size="size16">이제 결괏값을 어떤 형태로 받으면 좋을지 생각해보자. 우리가 만들것은 구구단이고 구구단 중 3단이다. 3단은 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">3, 6, 9, 12, 15, 18,..., 27이 될 것이다. 이런 종류의 데이터는 리스트 자료형으로 만들면 좋을 것 같다. 따라서 result = [3, 6, 9, 12, 15, 18, 21, 24, 27]과 같은 결과를 얻으면 좋지 않을까?</span></p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.3 생각해본것 적용해보기</h4>
<p data-ke-size="size16">결괏값을 어떻게 할지 생각해 본 것을 바탕으로 진짜 프로그램을 짜 보자. 먼저 times라는 함수를 만들자. 함수의 매개변수는 n으로 정하자.</p>
<blockquote data-ke-style="style3">def times(n):<br />&nbsp; &nbsp; &nbsp; &nbsp;print(n)</blockquote>
<p data-ke-size="size16">변수를 만든 뒤 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">times(3)를 실행하면 3을 출력하게 된다.</span></p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.4 리스트 생성하기</h4>
<p data-ke-size="size16">이제 결괏값을 담을 리스트를 만들어야한다. 앞에서 작성한 print(n)은 입력이 잘되는지 확인을 하기 위해 작성한 것이므로 지워주겠다.</p>
<blockquote data-ke-style="style3">def times(n):<br />&nbsp; &nbsp; &nbsp; result = [ ]</blockquote>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.5 리스트에 요소 추가하기</h4>
<p data-ke-size="size16">이제 result에 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">3, 6, 9, 12, 15, 18,..., 27을 넣어야 한다. 리스트에 요소를 추가하는 append 내장 함수를 사용해보자.</span></p>
<blockquote data-ke-style="style3">def times(n):<br />&nbsp; &nbsp; &nbsp; result = [ ]<br />&nbsp; &nbsp; &nbsp; result.append(n*1)<br />&nbsp; &nbsp; &nbsp; result.append(n*2)<br />&nbsp; &nbsp; &nbsp; result.append(n*3) <br />&nbsp; &nbsp; &nbsp; result.append(n*4) <br />&nbsp; &nbsp; &nbsp; result.append(n*5) <br />&nbsp; &nbsp; &nbsp; result.append(n*6) <br />&nbsp; &nbsp; &nbsp; result.append(n*7) <br />&nbsp; &nbsp; &nbsp; result.append(n*8) <br />&nbsp; &nbsp; &nbsp; result.append(n*9)<br />&nbsp; &nbsp; &nbsp; return result<br />print(times(3))</blockquote>
<blockquote data-ke-style="style3">[3, 6, 9, 12, 15, 18, 21, 24, 27]</blockquote>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.6 보수 공사하기</h4>
<p data-ke-size="size16">구구단이어서 그나마 다행이지만 만약 100단을 제작할려고 했다면 100번을 반복해야한다. 또한 지금도 함수의 반복이 너무 많아 보인다. 현재 반복되고 있는 부분을 보면 <span style="background-color: #fcfcfc; color: #666666; text-align: left;">result.append(n*?)의 ?위치에 1부터 9까지 숫자만 다르게 들어가 있다. 똑같은 일을 반복하기 위해 반복문을 사용하면 될 것 같다. 그렇다면 1부터 9까지 출력해주는 반복문을 한번 만들어 보자.</span></p>
<blockquote data-ke-style="style3">&gt;&gt;&gt; i = 1<br />&gt;&gt;&gt; while i &lt;10:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; print(i)<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; i = i+1</blockquote>
<blockquote data-ke-style="style3">1<br />2<br />3<br />4<br />5<br />6<br />7<br />8<br />9</blockquote>
<p data-ke-size="size16">잘 출력되는 것을 확인 되었으니 이제 이것을 times 함수에 적용해 보자.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.7 완성하기</h4>
<p data-ke-size="size16">이제 구구단 중 3단을 출력하는 코드를 완성해 보자.</p>
<blockquote data-ke-style="style3">def times(n):<br />&nbsp; &nbsp; &nbsp; result = [ ]<br />&nbsp; &nbsp; &nbsp; i = 1<br />&nbsp; &nbsp; &nbsp; while i &lt; 10:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;result.append(n*i)<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;i = i+1<br />&nbsp; &nbsp; &nbsp; return result</blockquote>
<p data-ke-size="size16">그렇다면 이제 테스트를 해볼까?</p>
<blockquote data-ke-style="style3">print(times(3))</blockquote>
<blockquote data-ke-style="style3">[3, 6, 9, 12, 15, 18, 21, 24, 27]</blockquote>
<p data-ke-size="size16">이렇게 결과도 원하는 대로 잘 나오는 것을 확인할 수 있다.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#3과 5의 배수 합하기</h4>
<p data-ke-size="size16">이번에는 문제를 하나 해결해 보겠다. 문제는 아래와 같다.</p>
<blockquote data-ke-style="style3">10 미만의 자연수에서 3과 5의 배수를 구하면 3, 5, 6, 9이다. 이들의 총합은 23이다.<br />1000 미만의 자연수에서 3의 배수와 5의 배수의 총합을 구하라.</blockquote>
<p data-ke-size="size16">그렇다면 이 문제를 어떻게 해결하면 좋을지 생각해 보자.</p>
<blockquote data-ke-style="style3">1000 미만의 자연수는 1부터 999를 말하니 1부터 999까지 입력받아야 겠다.<br />3의 배수와 5의 배수의 총 합을 구하라고 하였다. 이 값을 출력하면 되겠다.<br />그렇다면 3의 배수와 5의 배수는 어떻게 찾아야 할까?<br />3의 배수와 5의 배수가 중복 될 경우 어떻게 해야할까?</blockquote>
<p data-ke-size="size16">이 문제를 풀기위한 중요 포인트는 두 가지이다. 1000 미만의 자연수를 어떻게 구할 것인가?, 3과 5의 배수를 어떻게 구할 것인가?이다. 그럼 차례대로 이 문제를 해결해 보자.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.1 1000 미만의 자연수 구하기</h4>
<p data-ke-size="size16">먼저 1000 미만의 자연수를 구해 보자. 한번 변수에 초깃값을 1을 준 후 루프를 돌리며 1씩 증가시켜서 999까지 진행하는 방법을 사용해보자.</p>
<blockquote data-ke-style="style3">n = 1<br />while n &lt; 1000:<br />&nbsp; &nbsp; &nbsp; print(n)<br />&nbsp; &nbsp; &nbsp; n += 1</blockquote>
<p data-ke-size="size16">또는 range 함수를 사용할 수도 있을 것이다.</p>
<blockquote data-ke-style="style3">for n in range(1, 1000):<br />&nbsp; &nbsp; &nbsp; print(n)</blockquote>
<p data-ke-size="size16">코드를 실행하면 1부터 999까지 빠르게 출력되는 것을 확인할 수 있다.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.2 3과 5의 배수 구하기</h4>
<p data-ke-size="size16">이번에는 3과 5의 배수를 구해보자. 1000 미만의 자연수 중 3의 배수는 아래와 같이 증가할 것이다.</p>
<blockquote data-ke-style="style3">3, 6, 9, 12, 15, 18, ..., 999</blockquote>
<p data-ke-size="size16">그렇다면 1 부터 1000까지 수가 진행되는 동안 그 수가 3의 배수인지는 어떻게 알 수 있을까?</p>
<p data-ke-size="size16">1부터 1000까지의 수 중 3으로 나누었을 때 나누어떨어지는 경우, 즉 3으로 나누었을 때 나머지가 0인 경우가 바로 3의 배수이다. 따라서 아래와 같이 % 연산자를 사용하면 3의 배수를 쉽게 찾을 수 있다.</p>
<blockquote data-ke-style="style3">for n in range(1, 1000):<br />&nbsp; &nbsp; &nbsp;if n % 3 == 0:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;print(n)</blockquote>
<p data-ke-size="size16">그렇다면 5의 배수는 어떨까?</p>
<p data-ke-size="size16">3의 배수가 궁금했을 때 3으로 나누었을 때 나누어떨어지는 경우를 찾았다. 이와 마찬가지로 5으로 나누었을 때 나누어떨어지는 경우를 찾으면 될 것이다. 따라서 5의 배수는 n % 5가 0이 되는 수로 구할 수 있다.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.3 마무리하기</h4>
<p data-ke-size="size16">그렇다면 지금까지 해온 것을 총 정리해보자.</p>
<blockquote data-ke-style="style3">result = 0&nbsp;<br />for n in range(1, 1000):<br />&nbsp; &nbsp; &nbsp;if n % 3 == 0 or n % 5 == 0:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;result += n<br />print(result)</blockquote>
<p data-ke-size="size16">3과 5의 배수에 해당하는 수를 result 변수에 계속해서 더해주었다.</p>
<p data-ke-size="size16">하지만 3의 배수이면서 5의 배수인 15와 같은 수를 이중으로 더해서는 안된다. 그렇기 때문에 이중으로 더해지지 않기 위해 or 연산자를 사용하였다.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">#게시판 페이징하기</h4>
<p data-ke-size="size16">이번에는 게시물의 총 건수와 한 페이지에 보여 줄 게시물 수를 입력으로 주었을 때 총 페이지 수를 출력하는 프로그램을 만들어보자.</p>
<blockquote data-ke-style="style3">함수 이름은 page라고 하자.<br />게시물의 총 건수(m)와 한 페이지에 보여 줄 게시물 수(n)를 입력 받아야겠다.<br />출력하는 값은 총 페이지 수이면 될 것 같다.</blockquote>
<p data-ke-size="size16">이 프로그램을 만들 기 위해 입력값과 결괏값이 어떻게 나와야 하는지 먼저 살펴보자. 게시물의 총 건수가 5이고 한 페이지에서 보여 줄 게시물 수가 10이면 총 페이지 수는 당연히 1이된다. 만약 게시물의 총 건수가 15라면 총 페이지 수는 2가 될 것이다.</p>

<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.1 총 페이지수 얻기</h4>
<p data-ke-size="size16">총 건수(m)를 한 페이지에 보여 줄 게시물 수(n)로 나누고 1을 더하면 총 페이지 수를 얻을 수 있다.</p>
<blockquote data-ke-style="style3">총 페이지 수 = (총 건수 / 한 페이지당 보여 줄 건수) + 1</blockquote>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.2 코드 구성하기</h4>
<p data-ke-size="size16">위 공식을 적용했을 경우 총 페이지 수가 표의 값처럼 구해지는지 확인해 보자.</p>
<p data-ke-size="size16">(여기서 m을 n으로 나눌 때 소수점 아래 자리를 버리기 위해 / 대신 //연산자를 사용하였다.)</p>
<blockquote data-ke-style="style3">def page(m, n):<br />&nbsp; &nbsp; &nbsp; return m // n + 1<br /><br />print(page(5, 10))<br />print(page(15, 10)) <br />print(page(25, 10)) <br />print(page(30, 10))</blockquote>
<p data-ke-size="size16">첫 번째, 두 번째, 세 번째 케이스는 공식에 맞게 결과가 출력된다. 하지만 네 번째 케이스는 총 건수가 30이고 한 페이지에 보여 줄 건수가 10인데 4가 출력되어 생각한대로 결과가 나오지 않았다. 당연히 총 건수가 30이고 한 페이지에 보여 줄 건수가 10이라면 당연히 총 페이지 수는 3이 되어야 한다.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.3 해결하기</h4>
<p data-ke-size="size16">현재&nbsp; 총 게시물 수와 한 페이지에 보여 줄 게시물 수를 나눈 나머지 값이 0이 될 때 발생함을 생각할 수 있다. 이 문제를 해결할려면 아래와 같이 코드를 수정해야한다.</p>
<blockquote data-ke-style="style3">def page(m, n):<br />&nbsp; &nbsp; &nbsp; if m % n == 0:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp;return m // n<br />&nbsp; &nbsp; &nbsp; else:<br />&nbsp; &nbsp; &nbsp; &nbsp; &nbsp;return m // n + 1<br />print(page(5, 10))<br />print(page(15, 10))<br />print(page(25, 10))<br />print(page(30, 10))</blockquote>
<p data-ke-size="size16">나누었을 때 나머지가 0인 경우는 나누기의 몫만 돌려주고 그 이외의 경우에는 1을 더하여 돌려주도록 변경하였다. 한번 실행해 보면 잘 작동하는 것을 확인할 수 있다.</p></div>
