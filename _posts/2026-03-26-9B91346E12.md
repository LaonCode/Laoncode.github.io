            <div class="contents_style"><p data-ke-size="size16">#성적 판독기</p>
<p data-ke-size="size16">이번에 해결할 문제는 아래와 같다.</p>
<blockquote data-ke-style="style3">사용자로부터 학생 1 ~ 6의 성적을 각각 실수형으로 입력받고, 입력받은 값에서 전체 평균 성적을 소수점 아래 두 번째 자리까지 출력, 최고 점수와 최저 점수를 각각 소수점 아래 첫 번째 자리까지 출력<br /><br />단, 배열을 사용해야 하며 배열의 요소는 포인터 변수를 통해 접근해야 함</blockquote>
<blockquote data-ke-style="style3">학생 1의 성적을 입력하세요: 40.5 <br />학생 2의 성적을 입력하세요: 60.8 <br />학생 3의 성적을 입력하세요: 70.9 <br />학생 4의 성적을 입력하세요: 93.1 <br />학생 5의 성적을 입력하세요: 84.2 <br />학생 6의 성적을 입력하세요: 88.3<br /><br />전체 평균 성적: 72.97 <br />최고 점수: 93.1 <br />최저 점수: 40.5</blockquote>
<p data-ke-size="size16">문제를 확인해 봤으니 이제 만들어 보자. 위 조건들을 바탕으로 생각을 정리해 보면 아래와 같을 것이다.</p>
<blockquote data-ke-style="style3">학생 총 6명의 성적을 입력을 받을 때까지 입력하라는 메시지가 나와야 한다. &rarr; 반복문 사용<br />사용자가 각 학생에 대한 성적을 입력할 수 있어야 한다.<br />각 입력받은 성적 중 최고 점수와 최저 점수를 출력해야 한다.<br />전체 평균 성적을 소수점 아래 두 번째 자리까지 출력해야 하니 %.2f를, 최고 점수와 최저 점수를 각각 소수점 아래 첫 번째 자리까지 출력해야 하니 %.1f를 사용해야 한다.<br />배열을 사용하고, 배열의 요소는 포인터 변수를 통해 접근하도록 만들어야겠다.</blockquote>
<p data-ke-size="size16">그렇다면 이 생각을 바탕으로 코드를 구성해 보자.</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.1 변수 선언하기</h4>
<p data-ke-size="size16">먼저 사용할 변수를 선언할 것이다. 변수는 실수형 점수 6개를 담을 수 있는 배열 메모리, 포인터 변수를 선언하고 배열의 시작 주소를 저장할 수 있도록 만든다. 추가적으로 합계, 평균, 최고점, 최저점을 저장할 실수형 변수들을 만든다.</p>
<pre id="code_1774533787047" class="cpp" data-ke-language="cpp" data-ke-type="codeblock"><code>#include &lt;stdio.h&gt;

int main() {
    float score[6];
    float *ptr = score;
    float sum = 0, avg, max, min;
    int i=0;
}</code></pre>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.2 학생의 점수 입력받기</h4>
<p data-ke-size="size16">이제 학생 6명의 성적을 입력받아 보자. 점수는 총 6번을 입력받아야 하므로 while문을 통해 반복하여 만들었다. 또한 ptr로부터 i 만큼 떨어진 곳의 주소에 실수를 저장해 주기 위해 아래와 같이 코드를 작성하였다.</p>
<pre id="code_1774534515896" class="cpp" data-ke-language="cpp" data-ke-type="codeblock"><code>#include &lt;stdio.h&gt;

int main() {
    float score[6];
    float *ptr = score;
    float sum = 0, avg, max, min;
    int i=0;
    
    while(i&lt;6){
        printf("학생 %d의 점수를 입력하시오: ", i+1);
        scanf("%f", (ptr + i));
        i++
        }
    return 0;
}</code></pre>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.3 평균 점수 출력하기</h4>
<p data-ke-size="size16">이제 입력받은 값에서 전체 평균 성적을 소수점 아래 두 번째 자리까지 출력해 보려고 한다. 여기서 합계의 초기값은 0으로 설정하고 합계를 나타내는 sum값은 i번째 칸에 저장된 값을 가져와서 sum에 더하도록 만들었다.(이때 저장된 값을 가져와야 하니 앞에 *를 붙여야 한다.) 이렇게 모두 더한 sum값을 6으로 나눠 평균값을 구하고 이 값을 avg변수에 저장한다. 또한 평균 점수는 소수점 두 번째 자리까지 나타내라 했으므로 %.2f를 사용하였다.</p>
<pre id="code_1774536622056" class="cpp" data-ke-language="cpp" data-ke-type="codeblock"><code>#include &lt;stdio.h&gt;

int main() {
    float score[6];
    float *ptr = score;
    float sum = 0, avg, max, min;
    int i=0;
    
    while(i&lt;6){
        printf("학생 %d의 점수를 입력하시오: ", i+1);
        scanf("%f", (ptr + i));

        sum += *(ptr + i);
        i++;
        }
        
    avg = sum / 6;
    printf("평균 점수는 %.2f입니다.\n", avg);
    
    return 0;
}</code></pre>
<p data-ke-size="size16">&nbsp;</p>
<h4 style="color: #000000; text-align: start;" data-ke-size="size20">STEP.4 최대 점수, 최저 점수 찾기</h4>
<p data-ke-size="size16">이제 마지막으로 입력된 학생 6명의 점수 중 가장 높은 점수와 가장 낮은 점수를 소수점 첫 번째 자리까지 출력하도록 만들어 보자. 먼저 if문을 활용하여 판단하도록 만들었다. 가장 먼저 루프가 처음 돌 때 첫 번째 학생의 점수를 최고점과 최저점으로 정해놓았다. 이후 else문 부분에서는 두 번째(i=1) 학생부터 마지막 학생까지 첫 번째 학생과 비교를 시작하여 최고점의 경우 현재 가리키고 있는 학생의 점수가 현재 저장된 최고점보다 더 크다면 더 큰 점수로 교체를 한 것이&nbsp;된다. 최저점도 동일하게 현재 가리키고 있는 학생의 점수가 현재 저장된 최저점보다 더 작자면 더 작은 점수로 교체를 하게 된다. 예를 들어 1번 학생의 점수가 55.2점이라고 해보자. 2번 학생의 점수가 66점이라고 해보자. 처음에는 55.2점이 최고점이자 최저점일 것이다. 하지만 2번 학생의 점수가 입력되면서 66점이 55.2점 보다 크므로 최고점은 교체가 되고 최저점은 유지가 될 것이다. 또한 소수점 첫 번째 자리까지 출력하도록 만들기 위해 %.1f를 사용하였다.</p>
<pre id="code_1774536841438" class="cpp" data-ke-language="cpp" data-ke-type="codeblock"><code>#include &lt;stdio.h&gt;

int main() {
    float score[6];
    float *ptr = score;
    float sum = 0, avg, max, min;
    int i=0;

    while(i&lt;6){
        printf("학생 %d의 점수를 입력하시오: ", i+1);
        scanf("%f", (ptr + i));

        if (i == 0) {
            max = *(ptr + i);
            min = *(ptr + i);
        } else {
            if (*(ptr + i) &gt; max) max = *(ptr + i);
            if (*(ptr + i) &lt; min) min = *(ptr + i);
        }

        sum += *(ptr + i);
        i++;
    }

    avg = sum / 6;

    printf("평균 점수는 %.2f입니다.\n", avg);
    printf("최고 점수는 %.1f입니다.\n", max);
    printf("최저 점수는 %.1f입니다.\n", min);

    return 0;
}</code></pre>
<p data-ke-size="size16">이 코드를 실행해 보면 아래 이미지처럼 총 6명의 학생의 점수를 입력할 수 있도록 나오고 모든 학생의 점수 입력이 끝나면 평균 점수, 최고 점수, 최저 점수를 출력해 주는 것을 확인할 수 있다.</p>
