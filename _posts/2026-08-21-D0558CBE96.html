README에 이미지 추가하기

README에 이미지를 삽입하는 경우가 종종 있다. 마크다운에서 이미지를 삽입할 때는 맨 앞에 !를 붙인 후 대체 텍스트와 이미지 파일 경로를 지정한다. 대체 텍스트란 이미지를 나타낼 수 없는 상활일 때 그 자리에 어떤 이미지가 잇었는지 알려 주는 텍스트를 가리킨다. 시각 장애인을 위한 화면 낭독기에서 어떤 이미지가 있는지 읽어 주는 용도로도 사용한다.

![대체 텍스트](이미지 파일 경로)

그런데 README 파일에 이미지를 삽입하려면 사용할 이미지가 온라인에 있어야 한다. 여기에서는 깃허브 저장소에 이미지를 올려놓고, 그 이미지를 README 파일에 삽입하는 방법을 알아보겠다. 우선 저장소에 삽입할 이미지를 준비하자.

파일 목록이 보이는 저장소 첫 화면에서 +를 클릭한 후 Upload files를 클릭한다. 이후 파일 탐색기를 열어 깃허브 화면과 나란히 놓고, 업로드할 이미지를 선택한 후 깃허브 화면으로 끌어 옮긴다. 이후 이미지 파일 올리기가 끝나면 커밋 메시지를 작성하고 Commit changes를 클릭해 커밋해 준다.

깃허브 저장소 파일 목록에 방금 커밋한 메시지와 함께 업로드한 이미지 파일이 올라와 있는 것을 확인할 수 있다. 이제 이미지 파일을 README 파일에 넣어보자. README 편집 화면으로 이동해 준다.

![프로필 이미지](./파일 이름.png)

예를 들어 저장소에 업로드한 이미지를 삽입하려면 위와 같이 작성한다. [ ] 안에는 이미지의 대체 텍스트를 입력해 주면 된다. 이미지 파일 경로에서 ./ 는 현재 저장소 폴더를 가리킨다. Preview 탭을 클릭해서 제대로 나오는지도 확인해 주고 수정한 내용을 Commit changes... 를 클릭해 바꿔준다. 저장소 첫 화면으로 돌아가 보면 방금 README에 이미지를 추가한 커밋이 등록되어 있고, README 문서에도 추가한 이미지가 보일 것이다.
